# Claude Cowork 定时任务迁移调查

验证日期：2026-11-07。目标是把已有任务配置迁移到另一账号，而不是切换窗口或转移正在运行的任务。

[Anthropic 的定时任务说明](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)指出，任务使用账号中的连接器和文件；[Cowork 说明](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)说明云端定时任务可在电脑离线时运行。部分旧任务仍在电脑运行。因此，复制本地任务文件不等于已在目标账号创建云端计划，也不能停用原账号计划。

本机默认 Documents 位置未发现 `Claude/Scheduled` 目录；这不能证明不存在云端计划或其他位置的本地任务。本次没有读取任务内容、创建、修改或停止任务，也未找到可确认适用于个人账号的官方跨账号任务迁移接口。

建议先人工在目标账号重建测试任务，检查提示词、时区、频率、连接器、授权和文件位置，再分别在两个账号核对启停状态。若要开发自动迁移，先确认任务类型及官方支持的读写接口，并设计预览与去重；不能仅依据本地目录或假定关闭一个客户端就停止云端计划。
